# Telegram Бот-Переводчик и Стилизатор

Этот бот принимает текст, переводит его на русский язык и переформатирует в выбранном стиле.

## Запуск
1. Установите зависимости: `pip install -r requirements.txt`
2. Создайте файл `.env` с ключами `BOT_TOKEN`, `OPENAI_API_KEY` и `BASE_URL`.
3. Запустите: `python bot.py`
